📋 Genel Bakış

Remote Service Manager, Windows tabanlı uzak makinelerde servis durumlarını kontrol etmek, patch/güncelleme durumunu izlemek ve sistem metriklerini toplamak için kullanılan bir yönetim aracıdır.

🎯 Servis Kontrolü

Uzak makinelerde Windows servislerinin durumunu görüntüleme ve düzeltme

🔄 Patch Takibi

Windows güncellemelerinin durumunu ve bekleyen patch'leri izleme

📊 Metrik Toplama

Sistem performans, disk, bellek, network gibi bilgileri toplama

📌 Önemli: Bu uygulama tamamen lokal ağda çalışır ve internete çıkmaz. Tüm işlemler kurum içi ağ üzerinden yapılır.

🔧 Servis Tab - Butonlar ve İşlevleri

Parametreler Paneli

  • Servisler: Kontrol edilecek servis adlarını virgülle ayırarak girin (örn: WiaRpc, WinRM)
  • Dosya yolu: Uzak makinede kontrol edilecek dosyanın yerel yolunu girin (örn: C:\Program Files\app.exe)
  • Registry yolu: Uzak makinede okunacak registry anahtarını girin (örn: HKLM\SOFTWARE\Microsoft)
  • Registry value: Registry değer adını girin
  • Filtre: Tabloda filtreleme yapmak için kullanılır
  • Profil: Kaydedilmiş profilleri seçmek/düzenlemek için

Toplanacak Veriler (Metrics)

İşaretli metrikler tabloda sütun olarak görünür:

  • Running: Çalışan servisler
  • NotRunning: Çalışmayan servisler
  • FilePathControl: Dosya varlığı kontrolü
  • RegistryValue: Registry değeri okuma
  • Uptime: Sistem çalışma süresi
  • DiskInfo: Disk bilgileri
  • MemoryInfo: Bellek kullanımı
  • LoggedInUser: Oturum açmış kullanıcı
  • NetworkInfo: Network bilgileri
  • LastWindowsUpdate: Son güncelleme tarihi
  • Bsod: BSOD durumu
  • PendingUpdates: Bekleyen güncellemeler
  • OsBuild: İşletim sistemi build numarası

Butonlar

🔄 Patch Tab - Butonlar ve İşlevleri

Patch Metrikleri

Patch takibi için özel metrikler:

  • CcmExec: SCCM Client servisi durumu
  • Wuauserv: Windows Update servisi durumu
  • Bits: BITS servisi durumu
  • CryptSvc: Cryptographic servisi durumu
  • PatchBsod: BSOD dosya sayısı
  • UpdateSummary: Güncelleme özeti
  • PatchLoggedOnUser: Oturum açmış kullanıcı
  • PatchLastShutdown: Son kapanma tarihi

Butonlar

Buton İşlev
Tümünü Yenile Tüm makinelerde patch durumunu yeniden kontrol eder
Seçileni Yenile Tabloda seçili makinelerde patch durumunu yeniler
Seçili Servisleri Düzelt Seçili patch servislerini başlatmaya çalışır
İptal Devam eden işlemi iptal eder
Excel / CSV Patch tablosunu Excel/CSV formatında dışa aktarır
Sütunları Uygula Seçili patch metriklerini tabloya ekler
💡 İpucu: Patch tab, servis tabından bağımsız çalışır. Her tab kendi verilerini tutar.

📥📤 İçeri/Dışarı Aktarım (Import/Export)

Profil Kaydetme

  1. Servis/patch parametrelerinizi ayarlayın
  2. Metrikleri seçin
  3. "Profil Kaydet" butonuna tıklayın
  4. Profil adını girin
  5. Profil otomatik olarak şifreli şekilde kaydedilir

Profil Düzenleme/Silme

  • Profil seçin (Profil dropdown'ından)
  • Ayarları değiştirin ve "Profil Güncelle" butonuna tıklayın
  • Silmek için "Profil Sil" butonunu kullanın

Taşınabilir Export (Şifreli)

  1. Ayarlarınızı hazırlayın
  2. "Export Portable" seçeneğini kullanın (menüden)
  3. Kaydedilecek dosya yolunu seçin
  4. Şifre girin (en az 4 karakter)
  5. Şifreyi tekrar girin (onay için)
  6. Dosya şifreli olarak dışa aktarılır

Bu dosya başka makineye taşınabilir ve aynı şifreyle import edilebilir

Taşınabilir Import

  1. "Import Portable" seçeneğini kullanın
  2. Önceden export edilen dosyayı seçin
  3. Aynı şifreyi girin
  4. Ayarlar mevcut makineye yüklenir ve bu makineye bağlanır
⚠️ Güvenlik Notu: Export edilen dosyalar AES-256 ile şifrelenir. Şifreyi kaybederseniz dosyayı açamazsınız!

🔒 Güvenlik Özellikleri

✅ Şifreleme

  • AES-256-CBC şifreleme kullanılır
  • PBKDF2-SHA256 ile 100,000 iterasyonlu anahtar türetme
  • Makineye bağlı şifreleme (MachineGuid + MachineName)
  • Başka makineden kopyalanan config dosyaları açılamaz
  • Zamanlama saldırılarına karşı FixedTimeEquals
  • Hassas anahtarlar bellekten temizlenir

✅ Girdi Doğrulama

  • Hostname validation: UNC enjeksiyonu önlenir
  • Servis adı validation: WQL enjeksiyonu önlenir
  • WQL kontrolü: Sadece SELECT sorgularına izin
  • Registry kontrolü: Sadece HKLM/HKU kabul edilir
  • Path traversal kontrolü: ".." karakterleri reddedilir
  • UNC doğrulama: Sadece hedef makineye erişime izin

✅ Erişim Kontrolü

  • Registry okuma sadece okuma modu (writable: false)
  • Uzak makineler için admin share (C$) erişimi zorunlu
  • Ping tek başına yeterli kabul edilmez
  • WMI bağlantılarında PacketPrivacy (DCOM şifreleme)
  • 30 saniye timeout (donan makineleri önler)

✅ Dosya Güvenliği

  • 16MB maksimum dosya boyutu (DoS önleme)
  • Atomik dosya yazma (geçici dosya + move)
  • Dosya boyutu kontrolü
  • Bozuk config dosyaları otomatik yedeklenir

📁 Dosya Yönetimi

Config Dosyası

  • Konum: C:\Users\{kullanıcı}\Desktop\ServiceStatus\settings.rsmcfg
  • Format: Şifreli JSON
  • Şifreleme: AES-256 + Makine bağlama
  • Boyut limiti: 16MB
  • Yedekleme: Bozuk dosyalar otomatik yedeklenir (.broken_ zaman damgası)

Dosya Kaydetme Mekanizması

  1. Config değiştiğinde otomatik kaydedilir
  2. Önce geçici dosyaya yazılır (.tmp)
  3. Disk'e flush edilir
  4. Atomik olarak orijinal dosyanın yerine koyulur
  5. Elektrik kesintisi/çökme durumunda yapılandırma bozulmaz

Excel/CSV Export

  • Konum: Kullanıcı tarafından seçilir
  • Format: Excel (.xlsx) veya CSV
  • İçerik: Tablodaki tüm veriler
  • Şifreleme: Yok (plain text)

Export edilen Excel/CSV dosyaları şifreli değildir. Dikkatli saklayın!

Portable Export/Import

  • Konum: Kullanıcı tarafından seçilir
  • Format: .rsmcfg veya kullanıcı adı
  • Şifreleme: AES-256 + Kullanıcı şifresi
  • Taşınabilirlik: Başka makineye taşınabilir
  • Makine bağımlılığı: Yok (kullanıcı şifresiyle açılır)
⚠️ Önemli:
  • Config dosyası başka makineye kopyalanırsa açılamaz (makine bağlama)
  • Portable export şifresi kaybedilirse dosya kurtarılamaz
  • Excel/CSV export'ları hassas veri içerebilir, güvenli ortamda saklayın

❓ Sıkça Sorulan Sorular

Config dosyasını başka makineye taşıyabilir miyim?

Hayır. Config dosyası makineye bağlı şifrelenir. Başka makineye taşınmaz. Taşınabilir export özelliğini kullanın.

Şifremi unuttum, ne yapmalıyım?

Kurtarılamaz. Portable export şifresi kaybedilirse dosya açılamaz. Yeni bir config ile başlayın.

Uygulama internete çıkıyor mu?

Hayır. Tamamen lokal ağda çalışır. İnternet erişimi yoktur.

Hangi Windows sürümleri destekleniyor?

Windows 7 ve üzeri (WMI destekleyen tüm Windows sürümleri). .NET Framework 4.8 gerektirir.

Admin hakları gerekli mi?

Evet. Uzak makinelerde WMI, UNC share ve registry erişimi için admin hakları gerekir.

Aynı anda kaç makine kontrol edebilirim?

Varsayılan olarak 10 paralel işlem. Bu sayı kodda değiştirilebilir.
